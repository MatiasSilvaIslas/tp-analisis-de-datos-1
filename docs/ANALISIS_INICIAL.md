# Primeros resultados descriptivos (2014–2024)

Este resumen compara el primer trimestre de 2014 con el cuarto trimestre de 2024, usando los totales provinciales del archivo de accesos por tecnología de ENACOM.

| Indicador | 2014-T1 | 2024-T4 |
|---|---:|---:|
| Accesos totales | 6.398.398 | 11.925.620 |
| Accesos ADSL | 3.697.066 | 521.297 |
| Accesos Cablemódem | 2.407.330 | 5.625.728 |
| Accesos de fibra óptica | 150.323 | 4.875.163 |
| Participación de fibra óptica | 2,35 % | 40,88 % |
| Velocidad media ponderada estimada | 3,62 Mbps | 181,22 Mbps |

## Lectura inicial

- Los accesos totales sumados a nivel provincial aumentaron aproximadamente un 86,4 % entre los dos períodos comparados.
- La participación de fibra óptica pasó de aproximadamente 2,35 % a 40,88 % del total de accesos.
- Los accesos ADSL disminuyeron en el período, mientras que fibra óptica y cablemódem crecieron.
- La velocidad media ponderada estimada pasó de 3,62 Mbps a 181,22 Mbps. Este valor es un cálculo del proyecto a partir de velocidades medias provinciales ponderadas por accesos; no debe citarse como una medición nacional directa de ENACOM.

## Precauciones de interpretación

- Se comparan dos trimestres puntuales, no promedios anuales.
- El total de accesos es una suma de las 24 jurisdicciones para cada trimestre.
- La velocidad agregada es una estimación ponderada, con el método explicado en [`METODOLOGIA.md`](METODOLOGIA.md).
- Estos resultados son descriptivos; por sí solos no explican las causas de los cambios.
